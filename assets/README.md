# 🖼️ Preset-Bilder (Art Assets)

Diese Bilder gehören zu den Presets. So aktivierst du sie:

## Hochladen (einmalig, 5 Min.)

1. **discord.com/developers/applications** öffnen (Handy: Desktopwebsite an)
2. Deine App wählen (oder **New Application** erstellen)
3. Links **Rich Presence** → **Art Assets** → **Add Image(s)**
4. Bilder aus diesem Ordner hochladen
5. ⚠️ **Asset-Name EXAKT wie unten vergeben** (klein geschrieben, keine Leerzeichen!)

## Datei → Asset-Name → Preset

| Datei | Asset-Name | Preset |
|---|---|---|
| `vscode.png` | `vscode` | coding |
| `minecraft.png` | `minecraft` | gaming |
| `spotify.png` | `spotify` | musik |
| `netflix.png` | `netflix` | netflix |
| `youtube.png` | `youtube` | youtube |
| `twitch.png` | `twitch` | twitch |
| `fortnite.png` | `fortnite` | fortnite |
| `roblox.png` | `roblox` | roblox |

## Danach in Fufcord

1. **Application ID** deiner App kopieren → Fufcord Menü **Punkt 2** eintragen
2. Menü **Punkt 4** → Preset laden (z. B. `coding`)
3. Menü **Punkt 1** → starten 🚀

> 💡 Nach dem Hochladen ~5 Minuten warten — Discord braucht kurz.
> 💡 Name muss **1:1** stimmen (`vscode`, nicht `Vscode` oder `vscode.png`), sonst bleibt das Bild leer!
